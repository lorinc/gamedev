# p7 · Hex Caves (v5)

The Callisto design (D065, `concepts/callisto_design.md`) moves terrain and the path lattice into one
generator: wave function collapse on hexes. This prototype is its first half: generate the caves, in
layers, and look at them. The lattice (candidate tiles left uncollapsed) comes in the next prototype.
The full spec is [spec.md](spec.md).

## Question

Can a hex WFC with code-generated tiles and Markov-weighted pairing produce layered, organic-looking,
horizontally tiling caves, with no visible grid and few contradictions?

**Pass:** four random seeds side by side look like caves and corridors (the user's eye), not noise and not
a hex grid; ice, pudding and brine read as layers with natural transitions; the left and right edges join
seamlessly; restarts are rare; a map generates in well under a second.

**Kill:** whatever the knobs, the output reads as tiles or as noise, or contradictions dominate. Then drop
WFC for terrain and go back to CA caves with a lattice fitted afterwards.

## Assumptions

1. [?] Tiles generated by code from a few shape families give enough variety, with no hand-drawn tiles.
2. [?] Markov-weighted pairing makes structures continue (corridors run on, caves cluster), so the result
   reads as caves, not noise.
3. [?] Snapping each tile's edge band to its sockets, with noise only inside, hides the hex grid and still
   joins every edge seamlessly.
4. [?] Layers emerge from depth-dependent weights and materials in one pass, with natural transitions.
5. [?] Contradictions are rare enough that restarting is fine (a few restarts per map at most).
6. [?] A 16 × 32 map generates in under 100 ms in Node.

## Limitations

- [cut] The lattice: candidate tunnels, bridges and walls left uncollapsed. Next prototype.
- [cut] No character, traversal, building, ecology, bubbles, relics or light. Later prototypes.
- [cut] Reachability isn't enforced, only measured (cavity statistics per map). Enforcing it comes with
  the lattice.
- [constraint ?] Graphics are deliberately crude ("a 6-year-old in MS Paint", user): flat colours, black
  outlines. Is that enough to judge the shapes?
- [cut] A desktop tool page, not a phone layout.
