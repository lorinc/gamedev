# Stage 3: consolidate

Part of the [shape exploration](README.md). Done 2026-10-02. The pool ([01](01-broaden.md)) and its variants
([02](02-deepen.md)) are grouped by where they sit on Quantic Foundry's motivation map
([motivation-map.md](motivation-map.md)). The per-shape numbers are in [04-assess.md](04-assess.md).

**The grouping is Claude's inference.** It was made right after the user asked to map the pool to motivation mixes; the
user has not yet confirmed it.

## The result: two anchors, one add-on, one dial

The toy itself is **Discovery** (explore, tinker, experiment). Around it the pool gathers at two places, each matched
by a known game from Quantic Foundry's lists.

| | Anchor 1: experiment, then plan | Anchor 2: mine, and complete |
|---|---|---|
| Motivations | Discovery + Strategy | Design + Completion (with Discovery) |
| The game in the lists that is this mix | Kerbal Space Program | Animal Crossing, Pokémon |
| Shapes and variants | alchemy (3), diagnosis (16), harvest as steering (2b), pets as workers (4b, 6), rules for pets (4c, 18), the deadline (17), the card hand and deck-building run (1a, 22), the front (23) | caretaker (15), base (5), companion pets (4a), catalogue (11), lure and naturalist (4d, 25), creature requests (29), breeding and seed crafting (12, 21), visiting (19), traces, exhibit (28), one trigger (24) |
| Width on the map | compact (1.24) | Design alone or Completion alone: compact (0.92, 1.44). Both together: wide (2.36) |

**The add-on: Power.** It is the most central motivation on the map and as near the toy as Completion. It can be added
to either anchor.

- Shapes that bring it: loadout (1b), card collection (1c), harvest as yield (2a), idle factory (7), runs that keep
  something (10b), the random ladder's synergies (29b), character as centre (5b).
- This is where the user's "absurdly powerful" lives.

**The dial: difficulty.** Challenge means execution skill and high difficulty. No shape needs it; several reach it
only if the game is made hard.

- Shapes on the dial: runs (10), the card hand (1a, 22), orders (13), the front (23), the knowledge loop (26), async
  challenge (9), same start (27).
- How hard the game is belongs to the audience ([audience-factors.md](audience-factors.md), factor 6).

## Shapes that join the two anchors

| Shape | What it joins | Are the halves optional to each other? |
|---|---|---|
| "A beautiful ecosystem that also functions as an idle factory" (7, the user's fantasy sentence) | make it mine + plan and grow strong | open |
| Caretaker "required, but not enough" (15 + anything from anchor 1) | make it mine + experiment and plan | open |
| Character and base with a deck (5 + 1) | make it mine + plan | open |
| Prep cycle and run cycle (20) | prep: plan and design; run: grow strong, and test me if hard | no: each half needs the other |

Why the last column matters is in [04-assess.md](04-assess.md): a mix of far-apart motivations draws both groups when
each part can be enjoyed alone, and only the overlap when both are forced.

## Shapes that could order the whole game

Claude's note, not a grouping by motivation. Four shapes in the pool are less a mechanic than a candidate for what
decides the order in which a player meets everything else:

- tipping point as a new level (8)
- creature requests as a random ladder (29b)
- the expedition (14)
- the run (10)

Either anchor could use any of them.
