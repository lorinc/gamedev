# Stage 2: deepen

Part of the [shape exploration](README.md). Done 2026-10-02.

What deepening does here: some shapes in the [pool](01-broaden.md) are still blanket terms that hide several different
mechanics, and each mechanic would be judged differently in the assessment. Stage 2 splits them. It does not pick
between the variants: every variant goes to the assessment unless the user strikes it. **No variant was struck.**

## The variants

Shape numbers refer to the pool. Proposed by Claude unless the last column says otherwise.

| Shape | Variant | The loop | Where it came from |
|---|---|---|---|
| Cards (1, 22) | a. Hand | a deck grows during one outing; each moment a random hand is drawn from it and played | "deck builder" |
| | b. Loadout | a few slots filled between outings from what the player owns; during the outing it is just used | "a 'loadout' at all times, and it had constraints"; Noita |
| | c. Collection | cards are owned for good and gathered over weeks; decks are built from the collection | "if this was a CCG" |
| Harvest (2) | a. Yield | take what the cave produces; the take is the reward | "harvest the outcome" |
| | b. Steering | what is removed and what is left to seed decides what grows next; the take is the tool | "control the outcome by harvesting something and letting other things go into seed" |
| Pets (4, 6, 18, 25) | a. Companion | a creature is won and kept because it is cute or rare | "tamed animals are cute" |
| | b. Worker | a creature does a job inside the ecosystem that the player can't do | the SimCity comparison |
| | c. Rule-follower | the player sets standing rules; the creature follows them unattended | shape 18 |
| | d. Lure | the player raises the chance of a rare creature or event at a place | the user's turn on the naturalist |
| Run (10, 20, 22, 26) | a. Nothing kept | each run starts from zero; only the player's knowledge grows | "roguelike (not lite, there's no meta-progression)" |

| | c. The place kept | the run itself resets, but the environment the player prepared for it stays | shape 20 |

## What the user added

- **Creature requests as the ladder.** "This could be turned into the core progress ladder." Then: "The ladder would
  not be linear, but random and procgen, and this is where the insanely powerful random synergies could come in."
  - This gives the "absurdly powerful from random input" item of [brief.md](brief.md) a source: the random part is
    which creatures turn up and in what order; the knowledge part is seeing what this set can do together.
  - Two players, or two playthroughs, get different ladders. How often a fresh ladder is dealt is the unit-of-play
    factor ([audience-factors.md](audience-factors.md)).
- **Other players.** "Both are async, players can visit others' base, and players can challenge others async." So the
  user meant the visit and the async challenge.
- **Traces.** "Traces is an interesting idea, it could be a rare tamed creature showing up in someone else's world
  for a few days if conditions are met."
- **The deadline is a gate, not a disaster.** "When the event happens, prep reached the threshold for a
  world-changing event or not. If not, can try again later."
  - Enough preparation turns the event into a world-changing one; too little and nothing is lost.
  - This joins the deadline to shape 8 (tipping point as a new level): the event is the attempt to pass the tipping
    point.

The user closed the stage: "I'm good, let's map now these to motivation profile mixes."
